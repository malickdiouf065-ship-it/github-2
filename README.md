
# Teranga Restaurant 🇸🇳

Site web de restaurant spécialisé dans la cuisine sénégalaise.

## Technologies
- HTML5
- CSS3
- JavaScript

## Fonctionnalités
- Présentation du restaurant
- Menu de plats sénégalais
- Filtrage par catégorie
- Panier avec quantités
- Calcul automatique du prix total
- Préparation et copie d'une commande
- Design responsive pour téléphone et ordinateur

## Installation
1. Ouvrir le dossier dans Visual Studio Code.
2. Vérifier que les quatre fichiers sont dans le même dossier.
3. Installer l'extension Live Server si nécessaire.
4. Cliquer avec le bouton droit sur index.html.
5. Sélectionner Open with Live Server.

## Personnalisation
Modifiez les prix, les plats, les photos et les coordonnées
pour correspondre à votre restaurant.

Le site est une démonstration : la commande n'est pas encore
envoyée automatiquement au restaurant.
